# CHiLL Lab Demos

Interactive demos from the CHiLL Lab at UMass Boston.

Website: https://chill-umb.github.io/demos/

## How it works

Each folder in this repo is one demo. The folder name becomes part of the link:

```
demos/
├── index.html          → https://chill-umb.github.io/demos/
└── <demo-folder>/      → https://chill-umb.github.io/demos/<demo-folder>/
```

## Open it on your computer

Inside this folder, run:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/ in your browser.
